# 音声と字幕

## 手本を測った結果 (2026-11-11、大沢崩れの回 13 分 30 秒)

| 項目 | 値 | 測り方 |
|---|---|---|
| 声 | 合成音声の 2 人の掛け合い (概要欄では AquesTalk) | 概要欄、視聴 |
| 話す速さ | 話している間で 1 秒に約 6.9 文字 (間を含めると 5.9) | 自動字幕 4,798 文字 ÷ 無音を除いた時間 698.7 秒 |
| セリフの間 | 中央値 0.24 秒、9 割が 0.45 秒以下 | silencedetect (-32dB、0.18 秒以上) |
| 字幕 1 枚の長さ | 中央値 3.2 秒 (1 割が 1.7 秒以下、9 割が 5.0 秒以下)。13 分で約 250 枚 | 字幕帯を切り出してコマの変化を数えた |
| 字幕の形 | 1 セリフ 1 枚、最大 2 行。下の紺の帯に、話し手ごとに色を変えた太字 (黄と赤) | コマを目で見た |
| 字幕と画 | 字幕が変わるのと画のカットがだいたいそろう。1 ショット = 1〜2 セリフ | コマを目で見た |
| 音量 | -14.5 LUFS (YouTube の基準 -14 に近い)。BGM は声の下に小さく | ebur128 |

## VOICEVOX で合わせる

AquesTalk は商用で使うにはライセンスが要る。このテンプレートは VOICEVOX (Docker のエンジン、`http://127.0.0.1:50021`) を使う。

同じ文 (37 文字) を読ませて測った速さ (1 秒あたりの文字数):

| 声 | 速さ 1.0 | 1.2 | 1.35 |
|---|---|---|---|
| ずんだもん (speaker 3) | 4.9 | 5.9 | 6.6 |
| 四国めたん (speaker 2) | 5.7 | 6.9 | 7.7 |

手本の約 6.9 に近づけるなら、ずんだもんは 1.3〜1.4、四国めたんは 1.2。既定は 1.25。速すぎると聞き取りにくいので、本人に聞いてもらって決める。

## 書き方

```json
"voices": {
  "a": { "speaker": 3, "name": "ずんだもん", "speed": 1.3, "color": "#ffe94a" },
  "b": { "speaker": 2, "name": "四国めたん", "speed": 1.2 }
},
"tts": { "url": "http://127.0.0.1:50021", "padStart": 0.3, "pause": 0.25, "padEnd": 0.4, "wrap": 26 },
"bgm": { "src": "assets/bgm.mp3", "volume": 0.12 },
"shots": [
  { "from": {...}, "to": {...},
    "lines": [
      { "voice": "a", "text": "西側には、大沢崩れという大きな谷があるのだ。" },
      { "voice": "b", "text": "長さは約2km。", "speech": "長さは約2キロメートル。" } ] } ]
```

- `lines` のあるショットは、セリフの長さに合わせて伸びる (`padStart` + セリフ + `pause` + … + `padEnd`)。`duration` を書くと、それより短くはならない。
- 字幕は自動で入る。1 セリフ 1 枚で、次のセリフが始まるまで出ている。`wrap` 文字を超えると、真ん中に近い読点で 2 行に折る。字幕を出さないショットは `"subtitles": false`。
- `speech` は読み方。数字や略語、地名の読み違いを直す (字幕は `text` のまま)。
- 色は `voices` の `color`。省略すると黄、赤、水色、緑の順。
- `bgm` は声の下に音量 `volume` で敷き、繰り返す。最後に全体を -14 LUFS に合わせる (2 段階の loudnorm。実測で -14.5)。
- 合成した声は `out/<名前>/voice-cache/` に残る。同じ文・声・速さなら次から合成しない。
- 書き出すと `out/<名前>/credits.txt` に「音声：VOICEVOX:ずんだもん」などが入る。画面の右下にも出る。概要欄にも必ず書く (VOICEVOX とキャラクターごとの規約)。

## 確かめ方

- 下書き: `--no-voice` で声を合成せず、1 秒 6.5 文字として長さを決める (エンジン無しで構図を試せる)。
- 字幕と声のずれ: 字幕帯のコマの変化 (`crop` + `select=gt(scene,0.02)`) と、声の出だし (`silencedetect`) を比べる。テストでは全セリフで 0.08 秒以内だった。
- 声の聞こえ方、速さ、読み違いは数字では分からない。書き出したら本人に聞いてもらう。
