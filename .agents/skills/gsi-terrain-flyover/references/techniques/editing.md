# 編集の技法: カット、トランジション、時間と速度

用語の説明は本人が整理したもの (2026-11-12)。このテンプレートでできるかどうかは [README.md](README.md) の表。

## 1. カット・編集技法

- カット
  - 一つの映像から別の映像へ、効果を挟まず瞬時に切り替える最も基本的な編集技法。
- ジャンプカット
  - 同じ被写体を撮影した映像の途中を飛ばしてつなぎ、時間が突然進んだような不連続な変化を生み出す技法。
- マッチカット
  - 異なるシーンの構図、形状、動作などを一致させてつなぎ、視覚的な連続性や意味のつながりを生み出す技法。
- Jカット
  - 次のシーンの音声を先に流し始め、その後で映像を切り替える編集技法。
- Lカット
  - 前のシーンの音声を残したまま、映像だけを先に次のシーンへ切り替える編集技法。
- カットバック
  - 二つ以上の場面を交互に映し、同時進行する出来事や人物同士の関係を表現する技法。
- インサートカット
  - メインの映像の途中に、手元や物体などの詳細を示す短い映像を挿入する技法。
- モンタージュ
  - 複数の短い映像を組み合わせ、時間の経過、出来事の積み重ね、感情や意味のつながりを表現する技法。

## 2. トランジション・画面切り替え

- フェードイン
  - 黒画面などから映像を徐々に明るく、または不透明にして出現させる技法。
- フェードアウト
  - 映像を徐々に暗く、または透明にして消していく技法。
- ディゾルブ
  - 前の映像（シーンA）が徐々に消えていき、それと同時に次の映像（シーンB）が徐々に現れ、二つが重なり合いながら滑らかに切り替わる技法。
- ワイプ
  - 画面の端や特定の形状に沿って、新しい映像が古い映像を押し出すように切り替わる技法。
- アイリスイン・アイリスアウト
  - 円形の領域を広げたり縮めたりすることで、映像を出現・消失させる技法。
- フラッシュトランジション
  - 画面全体を一瞬白く光らせるなどして、その瞬間に別の映像へ切り替える技法。

## 3. 時間・速度の操作

- スローモーション
  - 映像を通常より遅い速度で再生し、動きを強調したり、劇的な印象を与えたりする技法。
- 早回し
  - 映像を通常より速い速度で再生し、長い動作を短時間に圧縮する技法。
- タイムラプス
  - 一定間隔で撮影した画像を連続再生し、雲の移動や建設作業など、長時間の変化を短時間で見せる技法。
- フリーズフレーム
  - 映像の特定の一コマを静止させ、時間が止まったように見せる技法。
- 逆再生
  - 映像を時間の流れと逆方向に再生し、動作が巻き戻されるように表現する技法。
- スピードランプ
  - 映像の再生速度を途中で滑らかに変化させ、通常速度からスロー、あるいは早回しへ移行させる技法。
