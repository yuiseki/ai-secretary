## このテンプレートでできるか

2026-11-12 の template/ を読んで確かめた。○ はできる、△ は近いことができる、× はできない。「参考動画」は `~/Workspaces/tmp/video-references/` の動画で見た例 (無いものは空欄)。

## もやし特集で足りなかったもの

v0.1.0 の感想は「画面は動いていても、同じパターンの繰り返し」。上の表で × と △ の多い所 (ショット間のトランジション、スプリットスクリーン、画面いっぱいの写真を動かす、効果音、音ハメ) は、参考動画が場面の型を切り替えるのに使っている技法と重なる。見直しの案は `~/Workspaces/tmp/yuisekintv/work/special-moyashi/v0.2_plan.md`。

## ドローン空撮からの設計

シーンの目的から技法と組み合わせを選ぶ際は [drone-camera.md](drone-camera.md) を読む。この一覧の従来の「パン」「ドリー」などの ○ は画面上の近似を含む。地図カメラの `center`・`zoom`・`pitch`・`bearing` は、実機の位置・姿勢・焦点距離をそれぞれ独立に指定するものではない。
