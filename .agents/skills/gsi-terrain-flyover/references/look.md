# 画の文法 (手本の映像を見て書き出したもの)

2026-11-11 に、土木・地理の解説動画のチャンネルを 2 本 (富士山の大沢崩れの回、八郎潟干拓の回) 見て書き出した。5〜8 秒おきのコマと 1 秒おきのコマを並べて確かめている。概要欄によると素材は、地理院タイル (全国最新写真、過去の空中写真)、Copernicus DEM、静岡県の点群、Natural Earth、OSM。

以下は観察した動画の傾向であり、固定の制作ルールではない。今回の主題や利用者の指定に合わせ、静止、広域移動、写真、図解も組み合わせる。詳しくは [camera-and-label-review.md](camera-and-label-review.md)。

## カメラ

- 1 ショットはだいたい字幕 1 行ぶん (4〜8 秒)。ショットの中でカメラは止まらず、ゆっくり動き続ける。ショットの切り替えはカット (つなぎの動きは無い)。
- 動きは 3 種類。寄る (zoom を 0.3〜0.6 上げる)、回り込む (bearing を 10〜20 度回す)、横に流す (center を少しずらす)。1 ショットで動かすのは 1〜2 種類まで。
- 斜めの角度は 55〜70 度。山は横から、平らな土地 (干拓地、扇状地) は 45〜50 度で上から寄りめに見せる。
- 見せたい物は画面の中央より少し上。下の字幕帯 (高さ 150px) にかからないようにする。
- 最初のショットは広く (zoom 10〜11.5)、話が進むにつれて寄っていく。章の頭でまた広く戻る。
- 高さは 1.3 倍ほど強調する (exaggeration)。強すぎると嘘っぽく、1.0 だと平たく見える。

## 重ね物 (このテンプレートの type との対応)

| 手本で見たもの | type | 使い方 |
|---|---|---|
| 川や谷を、上流から下流へ線が伸びて描かれる (青、強調はオレンジ) | `line` + `draw` | 線は白い縁取りつき。描き終わってから地名を出す |
| 範囲を半透明の色で塗り、白い線で囲う (遊砂地、干拓地) | `polygon` | 塗りは 0.3〜0.4 の透明度 |
| 地形の上に白い太字の地名。点つきのことも | `label` + `at` (`dot`) | 地図に貼り付くのでカメラと一緒に動く |
| 紫の札 (「八郎潟」「大沢川遊砂地」「現在」「過去」) | `label` + `style: "tag"` | 画面の左上か、地名の位置 |
| 左上の大きな数字 (「約2 km」「標高 2,500 m」「1969 年」「約40 年」) と、その上の小さな説明 | `counter` | 年は `grouping: false`。数え上げは `countUp`、年は `from` から |
| 暗くした地形の真ん中に「第2章」と章の題 | `chapter` | 章の頭の 3〜4 秒。カメラはほぼ止める |
| 右上の小さな「模式図」「資料に基づく復元」 | `note` | 線や範囲が実物どおりでないとき |
| 下の紺の帯に、話し手ごとに色の違う字幕 (黄と赤) | `lines` (自動) / `subtitle` | 1 セリフ 1 枚。測った数字は `narration.md`。色は `voices` の `color` |
| 右下の小さな出典 | 自動 (`credits`) | 消さない |
| 同じ場所の昔の空中写真と今の写真の切り替え | `base` (タイル) / `image` (自分でつないだ写真) | 札で「1974〜78年」「現在」を出す |
| 地形の上に広がる茶色の面 (たまった土砂、埋め立て) | `polygon` (塗り色を変える) | 量の変化はショットを分けて見せる |
| 論文や資料の一文を画面に引く | `quote` | 媒体名と日付を必ず添える。要約なら「」を外す |
| 写真や図を画面の一部に出す | `panel` | 出典を `credit` に |

## このテンプレートで作らないもの

- 3D の断面、建物、重機、ヘリコプターなどの CG (手本では別の 3D ソフト)
- 複雑な映像編集ソフト固有の写真加工 (通常の写真・図版は `panel` または `photo_marker` で挿入できる)
- 平面の県境地図 (Natural Earth を使った 2D 図)。必要なら別の静止画で作る

## 構成

- 冒頭にダイジェストを置く構成もある。本編の山場を 4〜5 カット (1 カット 1 セリフ、4 秒前後)、問いで終えてタイトルへ。数字は本編と同じものだけ使う (ダイジェストのための新しい主張を作らない)。JSON では `"digest": true` を付けたショットを先頭に並べる (目印で、動きは変わらない)。
- タイトルの最初のセリフは、ダイジェストと同じことを言わない。

## 素材

- この手本ではイラストに「いらすとや」、写真に Wikimedia Commons を用いた。依頼ごとの指定素材を優先し、作者・使用条件に応じた出典を画面に出す。
- いらすとやは 1 作品 20 点まで。画像は検索結果の `bp_thumbnail_resize("…/s72-c/<名前>.png", "<題>")` から取り、`/s72-c/` を `/s600/` に替えると大きい版になる。出典は「イラスト：いらすとや」。
- Wikimedia Commons は API (`action=query&prop=imageinfo&iiprop=url|extmetadata&iiurlwidth=1200`) で、ライセンス (`LicenseShortName`) と作者 (`Artist`) を一緒に取る。出典は「写真：<作者> / Wikimedia Commons (<ライセンス>)」。CC BY-SA は動画全体の扱いに関わるので、CC0、パブリックドメイン、CC BY を優先する。
- 日本の観光や文化の絵記号は EXPERIENCE JAPAN PICTOGRAMS (日本デザインセンター、https://experience-japan.info/) も使える。商用も無料、点数の制限なし、PNG と SVG。形を変えるのは禁止 (色、大きさ、丸や四角で囲むのは可)。アニメーション版は動画編集ソフトで編集し直して使わない。素材へ直接リンクしない。出典は必須でないが「素材提供：日本デザインセンター/EXPERIENCE JAPAN PICTOGRAMS」と入れる。規約は予告なく変わるので、使う前に /terms を読む。
- 写真は中身を目で確かめてから使う (「京葉工業地域」で探した写真が港のクレーンだった)。イメージ写真には caption に「(イメージ)」と書く。
