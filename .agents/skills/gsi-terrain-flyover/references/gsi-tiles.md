# 地理院タイルの種類と出典

URL は `https://cyberjapandata.gsi.go.jp/xyz/<ID>/{z}/{x}/{y}.<拡張子>`。2026-11-11 に応答を確かめた。

| ID (base / layer) | 中身 | 形式 | ズーム | 自動で入る出典 |
|---|---|---|---|---|
| `seamlessphoto` | 全国最新写真 (シームレス)。低ズームは世界の衛星モザイク | jpg | 2〜18 | 空中写真：国土地理院(地理院タイル「全国最新写真(シームレス)」)を加工 |
| `std` | 標準地図 | png | 〜18 | 地図：国土地理院(地理院タイル「標準地図」)を加工 |
| `pale` | 淡色地図 | png | 〜18 | 地図：国土地理院(地理院タイル「淡色地図」)を加工 |
| `relief` | 色別標高図 | png | 5〜15 | 地図：国土地理院(地理院タイル「色別標高図」)を加工 |
| `gazo1` | 1974〜78年の空中写真 (国土画像情報) | jpg | 10〜17 | 1974〜78年の空中写真：国土画像情報(カラー空中写真) 国土交通省 を加工 |
| `ort_old10` | 1961〜69年の空中写真 | png | 15〜17 | 1961〜69年の空中写真：国土地理院 を加工 |
| `ort_USA10` | 1945〜50年の米軍撮影の空中写真 | png | 15〜17 | 1945〜50年の空中写真：米軍撮影(国土地理院)を加工 |
| `ort_riku10` | 1936〜42年の陸軍撮影の空中写真 | png | 15〜17 | 1936〜42年の空中写真：陸軍撮影(国土地理院)を加工 |

- 過去の写真は範囲に抜けがある。`ort_USA10` と `ort_riku10` は秋田 (八郎潟) では 404、東京では 200 だった。使う前に `--stills` で写るか確かめる。
- `ort_*` は z15 より引いたカメラでは何も出ない (タイルが無い)。寄ったショットでだけ使う。
- `gazo1` の JPEG は、写真の無い所が真っ黒。`gsiclear` プロトコルで真っ黒を透明にして、今の写真が透けるようにしている。
- 範囲の抜けを埋めて全体を見せたいときは、「地図・空中写真閲覧サービス」の写真を自分でつないで `image` で貼る (手本の映像もそうしている)。

## 世界の引きの画 (NASA Blue Marble)

- 既定で、地理院の写真の下に NASA Blue Marble (海底地形つき、`BlueMarble_ShadedRelief_Bathymetry`) を敷く。NASA GIBS の Web メルカトルのタイル、z8 まで。
  `https://gibs.earthdata.nasa.gov/wmts/epsg3857/best/BlueMarble_ShadedRelief_Bathymetry/default/GoogleMapsCompatible_Level8/{z}/{y}/{x}.jpeg` (行と列の順が {y}/{x})
- カメラの zoom が `worldFade` の 1 つ目より引いていれば Blue Marble だけ、2 つ目より寄れば地理院の写真だけ、間は溶けるように切り替わる。既定は [5.5, 7]。海外の場所を z7〜8 で見せるなら [7.6, 8.8] くらいに上げる (地理院の世界モザイクは海に筋や欠けが出る)。
- `"world": "bluemarble-plain"` で海底地形なしの版、`false` で使わない。
- 出典は自動で「衛星画像：NASA Blue Marble (海底地形つき、NASA GIBS 経由)」が入る。

## 標高

- `dem: "gsi"` は標高タイル `dem_png` (z14 まで、基盤地図情報の数値標高モデル)。
- 値は `x = R×2^16 + G×2^8 + B`、`x < 2^23` なら `x × 0.01 m`、`x > 2^23` なら `(x − 2^24) × 0.01 m`、`x = 2^23` (RGB 128,0,0) は値なし。
- MapLibre はこの形式を直接読めない。`gsidem` プロトコルでブラウザの中で Terrarium 形式に変え、値なし (海、国外) は 0 m にしている。変換を直さずに MapLibre の custom encoding を使うと、値なしが 83,886 m の針になる。
- 海外の地形には別の標高 (Terrarium 形式の全球 DEM など) を `DEMS` に足す。そのときは出典も足す。

## 利用のきまり

- 地理院タイルは出典を書けば使える。加工したら「〜を加工して作成」と書く。テンプレートは自動で右下に出す。
- 過去の空中写真、国土画像情報も同じく出典を書く。
- サーバーに過度の負荷をかけない。書き出しは同時に 1 本まで。ブラウザは 1 回の書き出しの中でタイルを使い回すので、同じ場所を何度も読み直すことはない。
- 規約は変わることがある。公開する動画に使う前に、地理院の「地理院タイル利用規約」と、各タイルの説明ページを読む。
