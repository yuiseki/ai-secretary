# 問いの選び方

現状の表から1つ選ぶときの基準。上から順に見る。

## 外すもの

- 問いそのものが最近の論文で回収されている
- 評価器が実験や現地確認にしか無く、ソフトウェアだけでは答え合わせができない
- データが認証や申請の向こうにあり、再配布もできない

## 残すもの

- 正解表になる一覧が公開されている
- 1件のデータが小さく、API で取れる
- 既存の手順が対象から外した部分集合がはっきりしている

## 観察されている傾向

- 評価器が強い候補ほど混んでいる。検証が機械的にできると参入が進む
- 空きは分野の単位ではなく、部分集合の単位で残る。観測の頻度が低い標本、対象外にされた分類、別の言語の資料など
- 障壁が言語やデジタル化にあると当の分野の論文が書いている候補は、空きの信号が強い
- 混んでいる候補は、再発見の PoC に向いている。正解表も API も整っているためである。空いている候補は、正解表を自分で組むところから始まる

混んでいる候補で PoC をして手順を確かめ、同じ手順を空いている候補へ持っていく、という順にできる。ただし空いている候補が検出の形をしていないと、手順は持っていけない。気象の試走では、空きの信号が強かった候補 (くずし字の日記からの抜き出し、外国船の航海日誌との突き合わせ) は正解表が無く、復元の問いでもあった。

## 正解表を読むときに確かめること

- どうやって選ばれたか。分類器と目視の組み合わせなら、その分類器に似たスコアは高く出て当然である
- いつの時点の情報か。後から分類が登録されていると、その欄が答えを漏らす
- 元の論文が使ったデータと、自分が取れるデータは同じか
