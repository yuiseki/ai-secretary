# JLCPCB で作る

【部品選定・実装ルール】
・実装はJLCPCB。部品はBasic Partsのみ
・PCBAに載せる部品はLCSCで豊富な在庫があるもの
・手はんだ部品は秋月電子で在庫があるもの
・小さい部品はPCBAに任せること
・特殊な部品や調達しにくい部品は極力避ける
・パーツの種類や点数は減らすこと

目指すのは「設計できる」ではなく「実際に作れる安価な」基板。

## 進め方

1. 部品を決める前に、在庫とデータシートを確かめる。在庫が無い部品、データシートが読めない部品は、候補の表に「未確認」として残さず、候補から外す ([部品の探し方](references/search-parts.md))
2. 実装を頼む部品は、全部同じ面に置く。経済的な PCBA (Economic) は片面しか実装しない ([片面の実装](references/pitfalls/one-side-assembly.md))
3. BOM は LCSC の部品番号ごとに 1 行。CPL は部品の中心で書く ([BOM と CPL](references/pitfalls/bom-and-cpl.md))
4. 見積もりの画面で、組み立ての種類が「経済的」になっているかを見る。標準に回されたら、PCB の仕様が経済的な PCBA の組み合わせから外れている ([経済的な PCBA の条件](references/pitfalls/economic-pcba-spec.md))
5. 部品配置の確認画面で、向きのある部品 (IC の 1 番ピン) と、挿入部品 (ソケットなど) の位置を、1 つずつ目で見る。KiCad と JLCPCB では 0 度の向きが違う部品がある ([BOM と CPL](references/pitfalls/bom-and-cpl.md))

道具の入れ方は [install-deps.md](references/install-deps.md)。

## 発注の前に確かめること

- 部品の在庫と値段は、手元の部品 DB ではなく、その日のライブ検索で見る (DB は数か月前の版のことがある)
- CPL の Layer 列が、実装する部品すべてで同じ面 (Top) か
- 見積もりの組み立ての種類が「経済的」か。表面処理は鉛フリー HASL か (OSP だと経済的な PCBA を選べない)
- 確認画面で、IC の 1 番ピンの印と、基板の 1 番ピンの印が合っているか
- 挿入部品が、基板の穴の上に表示されているか (中心がずれていないか)

## 見積もりが急に高くなったら

値上がりと決めつけず、料金の内訳を見る。「設定料金」と「ステンシル」が数十ドルかかっていれば、標準 PCBA に回されている。原因は PCB の仕様 (表面処理、色、厚さ、枚数、端面スルーホールなど) か、両面の実装。部品代や基板代はふつう数ドルしか変わらない。
