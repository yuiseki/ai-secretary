# 実装を頼む部品は全部同じ面に置く

経済的な PCBA は片面しか実装しない。表面実装の部品も、ソケットなどの挿入部品も、実装を頼むものは全部同じ面 (ふつうは上面) に置く。

## よくある崩れ方

- ソケットを上面に移すために基板全体を左右反転すると、反対の面にあった IC やコンデンサが、もう一方の面に移る。反転は面を入れ替える
- 反転したあとで IC だけを元の面に戻すことはできない。SOIC などは、裏返すとピンの順が鏡像になり、回転では元に戻らない。反転する前の段階で、その IC を反対の面に描いておけば、反転のあとで同じ面にそろう (diy-kicad の [基板の反転](../../../diy-kicad/references/flip-board.md))
- 「確認画面で見る点」に回すと見落とす。面は設計の段階で守る条件として扱う

## 確かめ方

部品の面を変える変更 (反転、裏返し、移動) のたびに、書き出した CPL の Layer 列を見る。実装する部品がすべて Top であること。

```bash
cut -d, -f1,4 build/fab/*-cpl.csv
```

手はんだに回す部品があるときは、どれを人がはんだ付けするかを、作る人に先に聞く。小さい表面実装部品 (SOIC、0603、0805) は実装に任せる前提で設計されていることが多い。
